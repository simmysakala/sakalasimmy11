About Me

I am a first-year student at Mulungushi University, studying a programme that combines computer science with mathematics, physics, chemistry and communication skills. Projects and Skills

Four things I have learned, each with a program I wrote to practise it.

Palindrome checker

Skill: arrays and string handling in Python.

The program stores the characters in an array and compares the first and last items, moving inwards. I learned how to stop early when a mismatch is found.

Factorial and Fibonacci

Skill: recursion, flowcharts and pseudocode.

I drew the flowchart and wrote the pseudocode first, then coded both functions. Writing the base case before anything else stopped my recursion from running forever.

Recycle Bin cleaner

Skill: working with files in Python and Java.

I built the same utility in two languages and compared them. It taught me how each language handles files, errors and permissions.

Student attendance system

Skill: object-oriented design in Java.

A lab program that models students and their attendance with classes and constructors. It showed me why keeping data private inside a class makes code easier to trust.
