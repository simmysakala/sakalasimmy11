# simeon sakala - Interactive Personal Website (ICT251 Activity 3)

A responsive student portfolio built with plain HTML5, CSS and JavaScript for Mulungushi University.

**Live site:** https://YOUR-SITE.onrender.com

## Structure
- `index.html` - page content (About Me, My Hobbies, My Learning Plan, Projects, My Photos, My Media, Contact)
- `css/styles.css` - all styling, light and dark themes, responsive layout
- `js/script.js` - all interactive features
- `images/` - photos
- `videos/` - video and audio files

## JavaScript features and how to test them
1. **Contact form validation and preview (compulsory):** Submit empty fields, spaces only, and `abc@` as email; each shows an error. Enter valid details to see a local preview. No message is sent.
2. **Gallery viewer:** Use Previous and Next. Previous is disabled on photo 1 and Next on the last photo.
3. **Theme switch:** Click Dark mode / Light mode in the header. The choice is saved in the browser.
4. **Mobile navigation:** Narrow the window below 760 px, then open and close the Menu button (Escape also closes it).
5. **Extras:** project search with Reset and a no-match message; expandable project details; study hours calculator (days 1 to 7, hours 0 to 24).

## Deployment
Deployed from GitHub to Render as a Static Site (Build Command `echo "No build required"`, Publish Directory `.`).
